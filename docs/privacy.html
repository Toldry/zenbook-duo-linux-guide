Privacy policy

For the personal Google OAuth app rclone described on the home page. Last updated: 9 October 2026.

Who runs the app

The app is a Google Cloud client ID created by one person (“the owner”) for use with their own Google account, on their own computer, with the open-source program rclone. It isn't offered to anyone else.

What data the app accesses

With the owner's permission, given on Google's sign-in screen, the app accesses the files and folders in the owner's Google Drive, and their names and other metadata, through the Google Drive API. It uses this access only to show, copy and sync those files between Google Drive and the owner's computer, as the owner instructs rclone to.

Where the data goes

  • Data moves only between Google's servers and the owner's own computer.
  • The sign-in token is stored only on the owner's computer, in rclone's configuration file.
  • Copies of files are stored only on the owner's computer, where the owner decides to keep them.
  • The app has no server, database, analytics or advertising. No data is collected, sold, shared with or transferred to anyone else, and none is used to train AI or machine-learning models.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to remove access and data

  • Remove the app's access to your Google account at any time at myaccount.google.com/permissions.
  • Delete the local sign-in token with rclone config delete gdrive, and delete local copies of files like any other files on your computer.

Changes

If this policy changes, the new version is published on this page with a new date. Earlier versions are in the history of this file.
